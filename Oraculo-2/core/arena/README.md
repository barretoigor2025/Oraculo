# Arena

Sistema universal de mapa, combate e movimento.

## Responsabilidades

- carregar o cenario ativo
- posicionar pecas de tabuleiro
- controlar turnos
- calcular iniciativa
- executar movimento
- processar ataques
- calcular dano
- aplicar resultados
- registrar log da cena

## Entrada esperada

A arena deve receber entidades ja resolvidas pelo catalogo da campanha.

Cada entidade precisa trazer:

- dados de combate
- asset de peca_tabuleiro
- posicao inicial
- equipe ou lado
