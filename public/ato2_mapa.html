Ato 2 — Os Grimhollow Blackwoods (exploração livre)
Como funciona a exploração livre: Após entrar na floresta com Aelar, o grupo pode explorar as cenas em qualquer ordem — exceto quando um pré-requisito é necessário (🔒). Cada cena visitada vai sendo marcada no Firebase (cenasVisitadas). Quando todos os requisitos de uma cena bloqueada forem cumpridos, ela se torna disponível automaticamente no painel do narrador.

O narrador usa o 🗺 Mapa no painel de controles para ver o estado atual e navegar diretamente para qualquer cena disponível, sem precisar usar as setas ← →.
