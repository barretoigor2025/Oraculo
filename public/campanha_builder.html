Anatomia de uma Campanha — Cinco Pilares

Toda campanha é um cartridge autossuficiente em public/catalogo/{id}/. Alimenta os cinco pilares: Construtor (gera tudo), Narrador (NPCs por npcsPresentes), Catálogo, Arena e o Mapa do Mundo (Pilar 5).

Este builder gera os arquivos do novo modelo: campaign.js (cenas + npcsPresentes), npcs_registry.js, dados.json por NPC, e mapa.js (nós + caminhos). Regra de ouro: o ID de cada cena é também o ID do nó no mapa — é assim que viajar abre a cena certa no Narrador.

Estrutura de Pastas
public/catalogo/{id}/ ├── campaign.js ← em campanha/roteiro/ · CENAS + npcsPresentes ├── npcs_registry.js ← NPCS_REGISTRY (auto) ├── mapa.js ← NOS + CAMINHOS (Pilar 5) ├── mapa/mapa_{id}.png ← imagem do mundo (~2:1) ├── classes/{classe}/ │ ├── retrato/{classe}_m|f_retrato.png ← 512×768 mín │ └── peca_tabuleiro/{classe}_m|f_peca.png ← fundo verde #00ff00 ├── npcs/{npc}/ │ ├── dados.json ← fonte do registry │ ├── retrato/{npc}_retrato.png │ └── peca_tabuleiro/{npc}_peca.png ├── inimigos/{inimigo}/peca_tabuleiro/ └── cenarios/{cena}/ ├── imagem/{cena}.png ← cena de diálogo └── mapa/{cena}_mapa.png ← mapa de batalha
Especificações de Arte

📸 Retratos

Mínimo 512×768 · PNG/JPG · Foco rosto/busto · Qualquer fundo

🎭 Peças Tabuleiro

Corpo inteiro em pé · Fundo verde #00ff00 · PNG · Mínimo 400×800

🗺️ Interior (batalha)

Vista diagonal/isométrica · 1920×1080 · Espaço para peças

🏙️ Exterior (diálogo)

Establishing shot · 1920×1080 · Sem personagens em 1º plano

Arquivos a Criar / Modificar

➕ catalogo/{id}/campaign.js · npcs_registry.js · mapa.js — gerados nas Saídas
➕ catalogo/{id}/npcs/{id}/dados.json — um por NPC (gerado nas Saídas)
✏️ public/catalog.html — seletor + imports + paleta + branches das abas
✅ public/narration.html · mapa.html · arena.html — leem a campanha pelo localStorage, sem mudança estrutural

Script Chromakey (remover fundo verde das peças)
chromakey.py
from PIL import Image import glob for path in glob.glob('**/*.png', recursive=True): img = Image.open(path).convert('RGBA') px = img.load() w, h = img.size n = 0 for y in range(h): for x in range(w): r,g,b,a = px[x,y] if g > 80 and g > r*1.4 and g > b*1.4: px[x,y] = (0,0,0,0); n+=1 img.save(path) print(f'{path}: {n} px removidos')
SCHEMA_V — Evitar Conflito entre Campanhas

Cada arquivo simulacao_dialogo_{id}.html tem um SCHEMA_V inteiro que identifica o schema do doc Firestore. Use valores distintos por campanha:

Mhoried = 1 · Death Note = 4 · Próxima = 5 · …

Incremente sempre que mudar a estrutura do log para forçar recriação de sessões antigas.
